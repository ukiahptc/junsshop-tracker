쇼핑 검색 캡처 도구

네이버쇼핑 검색 결과를 북마클릿 한 번 클릭으로 긁어 data/shop/날짜.json으로 저장합니다. 가격을 손으로 적을 필요가 없습니다. · 분석 결과 보기

1. 북마클릿 등록 (최초 1회)

PC(Chrome·Edge): 아래 파란 버튼을 북마크바(즐겨찾기 모음)로 드래그합니다. 북마클릿이 갱신되면(현재 v2) 기존 북마크를 지우고 다시 드래그해야 합니다. 북마크바가 안 보이면 Ctrl+Shift+B.

아이폰 Safari: ① 이 페이지를 북마크에 추가 → ② 북마크 편집 → 방금 만든 북마크의 주소(URL)를 아래 "코드 복사"로 복사한 코드로 바꿔 저장. 이름은 "쇼핑 캡처"로.

준스샵 쇼핑 캡처

2. 검색어마다 한 번씩 클릭

  1. 네이버쇼핑에서 검색어 입력 (예: 호박고구마 3kg) → 정렬 네이버 랭킹순 확인
  2. 북마크바의 준스샵 쇼핑 캡처 클릭 → "n개 캡처, 클립보드에 복사됨" 알림
  3. 아래 3번 칸에 붙여넣기 → 추가. 다음 검색어로 반복 (11개 검색어 ≈ 3~5분)

검색 결과가 20개 미만으로 보이면 페이지를 아래로 한 번 스크롤한 뒤 클릭하세요. 네이버 화면 구조가 바뀌어 0개가 잡히면 README의 "캡처가 안 될 때"를 참고.

3. 붙여넣기 → 모으기

검색어상품 수준스샵스 순위캡처 시각

아직 모은 캡처가 없습니다. 모은 내용은 이 브라우저에만 임시 저장됩니다.

4. 저장

파일명 data/shop/YYYY-MM-DD.json

→ GitHub 저장소 data/shop/에 업로드 (Add file → Upload files)
GitHub에 바로 저장 (선택 · 토큰 필요)

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate: Repository access에 이 저장소만, Permissions → Contents: Read and write. 토큰은 이 브라우저의 localStorage에만 저장되며 서버로 보내지 않습니다.
